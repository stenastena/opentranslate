Electron accelerator format, e.g. Control+` or Alt+T.

When the detected language matches the first language, OpenTranslate translates to the second — and vice versa.

Cloud voices need an internet connection and use the same kind of unofficial, no-signup endpoint OpenTranslate already uses for translation — no account, no API key. If a cloud request ever fails, OpenTranslate automatically speaks that one request with a system voice instead, so Speak never just goes silent.

The per-language voices below configure the "System" source above, and are also what an automatic cloud-request fallback uses. Leave a language on "Automatic" to keep matching a voice to it by locale.

Windows' built-in voices are limited. For noticeably better quality, install the free, open-source — it adds Microsoft Edge's neural "Read Aloud" voices as ordinary system voices. OpenTranslate does not download or install anything itself; this only opens the project's page in your browser.
